# Удивительный Сахалин — ДОУ №10 «Росинка»

Готовый статический сайт для GitHub Pages.

## Что внутри
- `index.html` — главная страница.
- `museum.html`, `aniva.html`, `bagulnik.html`, `sterkh.html`, `lynx.html`, `whale.html` — шесть отдельных историй.
- `assets/style.css` — оформление.
- Кнопка «Послушать рассказ» использует встроенное озвучивание браузера (Web Speech API). Аудиофайлы и сервер не нужны.

## Как опубликовать на GitHub Pages
1. Войдите на https://github.com и создайте новый репозиторий, например `udivitelny-sakhalin`.
2. Выберите Public (для бесплатного GitHub Pages) и создайте репозиторий.
3. Распакуйте ZIP на компьютере.
4. Загрузите **содержимое папки** `udivitelny_sakhalin` в корень репозитория: `index.html`, шесть HTML-файлов, папку `assets` и `README.md`.
5. На GitHub откройте **Settings → Pages**.
6. В разделе **Build and deployment** выберите **Deploy from a branch**.
7. В Branch выберите **main**, папку **/(root)**, нажмите **Save**.
8. Подождите завершения публикации. Адрес сайта появится на странице Settings → Pages и будет примерно таким:
   `https://ВАШ-ЛОГИН.github.io/udivitelny-sakhalin/`

## Как проверить озвучивание
Откройте опубликованный сайт в актуальном Chrome, Edge или Safari и нажмите «Послушать рассказ». Доступные голоса зависят от устройства и установленных голосовых пакетов. На некоторых устройствах первый запуск может потребовать нажатия кнопки ещё раз.

## Как изменить текст
Откройте нужный HTML-файл и найдите текст соответствующего раздела. Сохраните изменения и загрузите файл в репозиторий — GitHub Pages обновит сайт автоматически.

## Важно
Сайт не использует базу данных, PHP или платные сервисы. Для озвучивания требуется поддержка синтеза речи браузером. Внешний Google Fonts используется только для шрифта; при отсутствии интернета сайт продолжит работать с системным шрифтом.
