Бесплатная публикация на GitHub Pages
1. Создайте новый репозиторий с именем whale-story и выберите Public.
2. Нажмите Add file → Upload files.
3. Загрузите index.html и нажмите Commit changes.
4. Откройте Settings → Pages.
5. В Build and deployment выберите Deploy from a branch.
6. Branch: main, папка: /(root), затем Save.
7. Через пару минут появится адрес вида https://ВАШ-ЛОГИН.github.io/whale-story/
8. Пришлите точный адрес — по нему можно сделать QR-код для печати.

Важно: после сканирования QR нужно нажать «Послушать». Телефоны обычно блокируют автоматический запуск звука без нажатия.
